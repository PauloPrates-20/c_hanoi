# Torre de Hanoi em C

===

Uma versão simples do jogo ***Torre de Hanoi*** desenvolvido em ***C***.

## Como rodar?

### Compilar através do código fonte

#### Linux:

```sh
git clone https://github.com/PauloPrates-20/c_hanoi.git
cd c_hanoi
make
out/main 3
```

3 é a quantidade mínima de discos. A quantidade de discos pode variar entre 3 e 7.

#### Windows:

- Faça download de um dos releases disponíveis
- Rode o executável diretamente ou
- Abra uma janela do cmd no diretório do arquivo executável e utilize o comando `<file>.exe <discos>`

`discos` pode ser qualquer número entre 3 e 7.

## Controles

- Mouse: Clicando nas torres
- Teclado: Com as teclas numéricas de 1 a 3 (representado as torres da esquerda para a direita)
